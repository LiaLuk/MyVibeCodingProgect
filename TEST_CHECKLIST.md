# Тест-чеклист «Орбита знаний»

Проверки выполняются локально и повторяются после публикации сайта.

Обозначения:
- [ ] — ещё не проверено или требуется исправление.
- [x] — проверено, работает.

## Главная страница

- [ ] Отображаются название и описание приложения.
- [ ] Отображается изображение планеты.
- [ ] Кнопка «Начать викторину» открывает вопросы.
- [ ] Кнопка «Посмотреть прогресс» открывает статистику.
- [ ] При незавершённой попытке появляется кнопка «Продолжить викторину».

## Викторина

- [ ] Загружаются 10 вопросов из data.json.
- [ ] У каждого вопроса четыре варианта ответа.
- [ ] До выбора варианта проверка ответа недоступна.
- [ ] Можно изменить выбор до проверки ответа.
- [ ] Правильный ответ добавляет один балл.
- [ ] Неправильный ответ не добавляет баллы.
- [ ] После проверки отображается правильный ответ и объяснение.
- [ ] После проверки нельзя изменить ответ.
- [ ] Повторные нажатия не начисляют дополнительные баллы.
- [ ] Номер вопроса и индикатор прогресса обновляются.
- [ ] После десятого вопроса отображается итог.
- [ ] Результат одной попытки записывается в историю только один раз.

## Сохранение

- [ ] После обновления страницы проверенные ответы сохраняются.
- [ ] После закрытия и повторного открытия сайта можно продолжить попытку.
- [ ] Завершённые попытки отображаются в истории.
- [ ] Лучший результат соответствует истории попыток.
- [ ] Новая попытка не удаляет историю.
- [ ] Сброс незавершённой попытки требует подтверждения.
- [ ] Отмена сброса сохраняет текущую попытку.

## Интерфейс

- [ ] Все три изображения отображаются на соответствующих экранах.
- [ ] Текст читается без увеличения.
- [ ] На узком экране нет горизонтальной прокрутки.
- [ ] Кнопки не перекрывают друг друга.
- [ ] Кнопки и ссылки доступны с клавиатуры через Tab.
- [ ] Фокус клавиатуры виден.
- [ ] Результат ответа обозначается текстом, а не только цветом.
- [ ] При отсутствии истории показано понятное сообщение.

## После публикации

- [ ] Сайт открывается по публичной ссылке.
- [ ] CSS и JavaScript загружаются.
- [ ] data.json загружается.
- [ ] Все изображения доступны.
- [ ] Викторину можно пройти до конца.
- [ ] Прогресс сохраняется после обновления опубликованного сайта.

## Найденные ошибки

Для каждой ошибки записать:
1. Что сделали.
2. Какой результат ожидали.
3. Что произошло на самом деле.
4. Исправлена ли ошибка.
